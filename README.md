# Arctic Combat
My first project, the project that got me into coding + reverse engineering with a very long backstory behind it.



# Summary of gameplay stuff
* Dynamic Viewmodel Adaptation (Corner Slice / Wall Push)
* Night Maps
* CQB Maps
* Custom Maps (10+ maps)
* Custom Weapons (10+ weapons)
* Custom Characters (10+ characters)
* Custom Skins (20+ weapons skins)
* Custom Modes (20+ modes)
* Dedicated Servers
* FOV & Viewmodel FOV changer
* Reworked Weapon sway
* ADS Walking bob/sway
* FPS Unlocker
* Increased Server tick rate
* Alt-Tab block removed
* Sprint while reloading
* Omnidirectional Sprinting (all directions)
* Hold ADS support
* Emojis & hyperlinks in game chat
* Health Bars
* Damage Numbers
* 3D World pings
* Player chat colors
* Player nickname colors
* Player banners
* True First Person (legs & feet visible)
* Voice Chat + Proximity Voice Chat
* Auction House
* Fire Mode changer (Single, Burst, Full Auto, only on SMGS, ARs, LMGs)
* Freely Drop/Throw weapon


# Tools
* Map Editor/Maker
* Client Editor
